## Daily workflow

1. Open the day's README and read the learning goal.
2. Write the code locally using VS Code.
3. Run it and test normal and error cases.
4. Note what you learned in that day's README.
5. Stage, commit and push meaningful changes.

```bash
git add .
git commit -m "feat: complete day 1 Python error handling"
git push origin main
```

Adjust the commit message to describe what was actually completed. Keep API keys, passwords, personal data, real datasets and company code out of this public repository.
